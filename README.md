# Meu Banco de Horas

App de bolso para bater ponto e acompanhar o saldo do banco de horas, em uma única página HTML (`index.html`).

- Botão de ponto (entrada, almoço, volta, saída; sábado com entrada e saída)
- Saldo do banco, resumo da semana, plano para zerar o saldo e histórico
- Regras da empresa configuráveis em Ajustes
- Lembretes no app e exportação `.ics` para a agenda do celular

Fora do Claude, os dados ficam salvos no `localStorage` do navegador. Basta abrir o `index.html` ou publicar com GitHub Pages.
