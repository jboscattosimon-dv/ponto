# Ponto · Meu Banco de Horas

App de bolso para bater ponto e acompanhar o saldo do banco de horas. Uma página só (`index.html`), publicada pelo GitHub Pages.

- **Hoje:** saldo, gráfico do mês, botão de ponto, horário ideal de saída e avisos
- **Semana:** barras por dia, plano para zerar o saldo e regras da empresa
- **Histórico:** calendário do mês com crédito/débito e lista de dias editáveis
- **Ajustes:** regras, lembretes na agenda do celular, tema e sincronização

Os dados ficam no navegador de cada aparelho. Para passar para outro aparelho use **Ajustes → Enviar link com meus dados** (ou backup em arquivo).
